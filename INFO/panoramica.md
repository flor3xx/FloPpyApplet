# FloPpy Applet

Applet Cinnamon in italiano per monitorare localmente le sessioni opencode, il master e i sotto-agenti.
Il popup dell'applet contiene la dashboard completa. Un daemon Python locale raccoglie gli eventi dal plugin opencode, aggiorna lo stato, calcola i token e invia notifiche Cinnamon.

Vincoli: nessun cloud, server solo su 127.0.0.1, nessuna modifica ai provider OmniRoute, poche dipendenze, installazione semplice.

Il repository GitHub di riferimento è https://github.com/flor3xx/FloPpyApplet.git.
